
# 💼 Job Application Form using Streamlit

This is a simple and user-friendly Job Application Form built using **Streamlit**. It allows users to enter their personal and educational details, upload their resume, and submit the form for job application purposes.

## 🚀 Features

- Collects user information like:
  - First Name
  - Last Name
  - Email Address
  - Phone Number
  - Address
  - Education & Stream
  - Year of Passing
  - Resume Upload
- Form validation for required fields
- Resume upload support (`.pdf`, `.doc`)
- Simple, interactive UI
- Submission success animation 🎈

## 🛠️ Tech Stack

- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/)


## 🚀 How to Run

1. **Clone the Repository**  
   ```bash
   git clone https://github.com/Abinanthanan08/streamlit-job-application-form.git
   cd streamlit-job-application-form
   ```

2. **Create a Virtual Environment**  
   ```bash
   python -m venv venv
   ```

3. **Activate the Virtual Environment**  
   - On macOS/Linux:
     ```bash
     source venv/bin/activate
     ```
   - On Windows:
     ```bash
     venv\Scripts\activate
     ```

4. **Install the Required Dependencies**  
   ```bash
   pip install -r requirements.txt
   ```

5. **Run the Streamlit App**  
   ```bash
   streamlit run app.py
   ```

   Then, open your browser and navigate to `http://127.0.0.1:8501` to start using the app!
